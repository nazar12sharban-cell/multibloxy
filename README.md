# MultiBloxy

Приложение для одновременного управления несколькими окнами Roblox.

## Возможности

- 🎮 Управление всеми окнами Roblox одновременно
- ⌨️ Синхронизация клавиатуры и мыши
- 🔑 Кастомные горячие клавиши для Start/Stop
- ⛔ Кнопка отключения управления на всех окнах
- 📊 Удобный графический интерфейс (UI)

## Системные требования

- Windows 10+
- Python 3.8+
- Минимум 2 окна Roblox для использования

## Установка и запуск

### Вариант 1: Использование Python

1. Установи зависимости:
```bash
pip install PyQt5 pynput pywin32
```

2. Запусти приложение:
```bash
python main.py
```

### Вариант 2: Скомпилированный .exe (рекомендуется)

Просто запусти `MultiBloxy.exe` из папки `dist/`

## Использование

1. **Открой 2 или более окна Roblox**
2. **Запусти приложение**
3. **Нажми "Set Hotkey" и выбери любую клавишу**
4. **Нажми "Start"**
5. **Используй выбранную горячую клавишу для включения/отключения управления**
6. **Нажми "Disable All" чтобы отключить управление на всех окнах сразу**

Когда управление активно (статус ACTIVE):
- Все движения мыши синхронизируются на все окна
- Все нажатия клавиш отправляются на все окна
- Клики мыши работают на все окна одновременно

## Файлы проекта

- `main.py` - точка входа приложения
- `ui.py` - интерфейс PyQt5
- `window_manager.py` - управление окнами Roblox и синхронизация
- `hotkey_handler.py` - обработка горячих клавиш
- `requirements.txt` - зависимости Python
